# midirec-ai

Repository: https://github.com/gadgetmies/midirec-ai

Client-only web app for recording MIDI to newline-delimited JSON, editing on a timeline, and playing back to selected devices. Planned stack: Vite, React, TypeScript, Web MIDI API, static hosting on GitHub Pages.

See the project plan in Cursor for full scope.

## Requirements

- Chromium-based browser (Web MIDI)
- HTTPS (required for Web MIDI; satisfied on GitHub Pages)

## Development

Scaffold and scripts will be added with the initial Vite application.
